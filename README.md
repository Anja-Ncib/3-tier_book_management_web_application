3-Tier Book Management Web Application

----------------------------------------------------------------------------------
A scalable and maintainable 3-tier web application developed using Java, Servlets, and Apache Tomcat, designed to manage books and users efficiently. The system follows a clear separation of concerns (Presentation, Business Logic, Data Access), ensuring modularity and ease of maintenance.

----------------------------------------------------------------------------------
Features:

  - User Authentication
    
      Secure login system for administrators and clients
    
      Role-based access control
    
  - Book Management
    
      Add, update, delete, and view books (admin)
    
      Browse and search books by author
    
  - Dynamic Data Handling
    
      Real-time interaction with the database
    
      Efficient data retrieval and updates
    
----------------------------------------------------------------------------------

3-Tier Architecture:

    - Presentation Layer: JSP/HTML interfaces
    - Business Logic Layer: Java Servlets handling application logic
    - Data Access Layer: Database connectivity and queries (JDBC)
----------------------------------------------------------------------------------

Tech Stack:

    - Backend: Java, Servlets
    - Frontend: JSP, HTML, CSS
    - Server: Apache Tomcat
    - Database: MySQL (via JDBC)
----------------------------------------------------------------------------------

Architecture Overview

The application is structured into three main layers:

    Presentation Layer
    Handles user interface and interactions
    Displays dynamic content using JSP
    Business Logic Layer
    Processes client requests
    Implements core functionalities (authentication, book operations)
    Data Access Layer
    Manages communication with the database
    Executes SQL queries and returns results
----------------------------------------------------------------------------------

Deployment

    - Configured and deployed on Apache Tomcat Server
    - Follows standard WAR packaging
    - Ensures portability and scalability across environments
----------------------------------------------------------------------------------

Key Learnings

    - Designing scalable systems using 3-tier architecture
    - Implementing authentication and role-based systems
    - Managing database connectivity with JDBC
    - Deploying Java web applications on Tomcat
